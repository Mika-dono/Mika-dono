### 🌍 Featured Project — TerraBond

> **TerraBond — Connect Beyond Borders.** An AI-powered social network dedicated to travelers, built as my final-year engineering project (PFE 2026).

A full-scale platform combining a social feed, ephemeral stories, real-time messaging, a community forum, nomad job offers, travel deals & events, an admin analytics dashboard — and an **AI assistant (RAG)** that answers travelers' questions and recommends compatible travel companions in real time.

**Highlights**
- 🧠 **AI assistant (RAG)** powered by Groq / Llama 3.3, fed live with platform data to recommend compatible profiles and answer questions.
- 💬 **Real-time messaging & stories** over WebSocket / STOMP (typing indicators, read receipts, story replies).
- 📱 **Reactive frontend** in Angular 17 (standalone components, signals, NgRx) with Tailwind, Three.js & Google Maps.
- ⚙️ **Robust backend** in Spring Boot 3 / Java 17 — JWT + BCrypt auth, RBAC, OTP email verification, Flyway, rate limiting, Swagger/OpenAPI.
- 📊 **Admin analytics dashboard** — KPIs, retention, funnels, activity heatmaps & CSV export (Chart.js).
- 🐳 **Dockerized** stack (PostgreSQL + Redis + backend + AI service + frontend) for one-command deployment.
